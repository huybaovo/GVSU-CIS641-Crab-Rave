# Introduction

GODOT engine is considered a lightweight engine for small scope projects or small development teams. For this project, we will be using GODOT for the creation of a 2D side scrolling game with some extra features. Additionaly, there will be incopreration of assets that are beach themed in creation of the platformer.<br>
In creation of a beach theme platformer, we will learn the strengths and weaknesses of using GODOT in comparison to using other possible game engines for game development like Unity or Unreal. While we will being comparing GODOT, the project will be focused on creating a simple fun 2D platformer with infinite side scrolling as the end goal.

# Anticipated Technologies

GODOT 4.7.2 or the latest version and itch.io assets will be the only needed technologies for the development of this project. 

# Method/Approach

The plan is to implement different modules and functions of the platformer incrementely for each sprint or meeting done by the team following SCRUM. Each function implemented should also be tested by exploratory testing to see how the game would run. 

# Estimated Timeline

For major milestones, the base game platforming should approximately take 2-4 weeks with learning the GODOT engine and applying it to creation of the foundation which is the game. Highscore tracking should be done in about 1-2 week with adding additional functions to the base game. Then menu creation and executable file will approximately take 1-2 weeks to create alongside integration of the other features into it. Additional, if the milestones are met early the time frame will be used to flesh out the game more on featurs that need more work.

# Anticipated Problems

- Learning GODOT engine will be the hardest part as it will be similar to learning a new language.
- Working with assets from itch.io to be pulled an used in the GODOT engine.
- Optimizing the application so that it will be lightweight to run on most PC hardware.
